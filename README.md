
# Mercado Boa Compra

Sistema de Controle de Estoque para Pequeno Mercado.

## Sobre o projeto

Projeto acadêmico desenvolvido no curso de Análise e
Desenvolvimento de Sistemas (ADS), na disciplina
Projeto de Software.

O sistema utiliza um mercado fictício como estudo de
caso para demonstrar uma solução de controle de estoque.

## Objetivo

Desenvolver uma aplicação web que permita cadastrar
produtos, registrar entradas e saídas de mercadorias,
consultar quantidades disponíveis e identificar
produtos com estoque baixo.

## Tecnologias

- Python 3.12
- Flask 3.x
- HTML5
- CSS3
- JavaScript
- SQLite
- Git e GitHub

## Funcionalidades planejadas

- Cadastro de produtos
- Registro de entradas e saídas
- Consulta de estoque
- Alertas de estoque baixo
- Autenticação de usuários

## Situação do desenvolvimento

Etapa 1: configuração inicial do ambiente e
primeira página Flask funcionando localmente.

## Execução local

1. Criar e ativar um ambiente virtual Python.
2. Instalar as dependências:

   pip install -r requirements.txt

3. Executar:

   python app.py

4. Acessar http://127.0.0.1:5000

## Observações

Projeto acadêmico em desenvolvimento.
Os dados utilizados serão fictícios.
